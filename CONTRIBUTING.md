# Contributing to ClaimLens

Thank you for helping improve ClaimLens.

## Before opening a pull request

- Explain the problem and the change clearly.
- Add or update tests for changed behavior.
- Run `python -m pytest -q`.
- Do not include tokens, passwords, private data, or generated reports.
- Keep changes focused and easy to review.

ClaimLens provides evidence for maintainers; it must not automatically reject
contributors or make unsupported security claims.
